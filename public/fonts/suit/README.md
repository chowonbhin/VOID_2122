# SUIT Variable

- Designer: SUNN. Official project: https://sun.fo/suit/
- Source repository: https://github.com/sun-typeface/SUIT
- Pinned commit: `55118d981336d8fce005eb62888c12c0568ef7b0`
- Original file: `fonts/variable/woff2/SUIT-Variable.woff2` (624,536 bytes).
- Unmodified upstream font, 100–900 weight axis. Licence: [SIL OFL 1.1](OFL.txt).

One local variable font supplies Korean, Latin and numerals throughout the app.
`src/typography.css` uses `font-display: swap`; `index.html` preloads the same URL.
There are no remote font requests, separate files for each weight, or subsets
that omit rare Korean place names or user-written notes.
