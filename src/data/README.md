# 안산 탐험 콘텐츠와 유동인구

2026-11-08 반영. 사용자가 기존 유동인구 감점 정책과 실제 권역, 지도 중심 추천을 요청하여 연결했다.

## 자료와 계산

- `footfall.json`: 제공된 `assets/안산/03_상권_동_비중표_1.png`의 18개 행을 전사했다. 기준은 2026년 8월, 조회일은 2026년 11월 7일이다.
- 지표는 소상공인365 발달상권의 일평균 유동인구. 고유 방문자 수, 안산 전체 인구, 실시간 혼잡도가 아니다.
- 원본 이미지와 대조한 18개 수치 합계는 466,765다. 동 이름은 원본의 사이트 표시값을 보존한다.
- F = 해당 탐험권역에 명시적으로 연결한 상권 수치 합계 / 466,765. 검색 결과, 관심사, 최대 거리로 분모를 다시 계산하지 않는다.
- α = −f(지역 Lv) × F. Lv.0은 감점하지 않는다. 같은 Lv에서 유동인구가 많을수록, 같은 유동인구에서 Lv이 높을수록 감점한다.
- f(0/1/2) = 0/10/20은 이번 구현의 초기 조정값이다. 원문에 이미 확정된 숫자나 실측으로 추정한 계수가 아니다. `src/domain/policy.ts`에서 조정한다.
- 지역 점수 = max(0, 장소 점수 합계 + α) × 새로움 배율 × 거리 가중치. 누락/중복/잘못된 자료는 감점을 보류하고 미반영 상태로 반환하며 실제 유동인구 0과 구분한다.

- 다문화거리: [안산시 문화관광](https://ansan.go.kr/tourinfo/common/cntnts/selectContents.do?cntnts_id=C0001976). 다문화길 16 일대와 안산역을 함께 묶었다.

- `boundary`는 앱에서 직접 지정한 대략적인 탐험 범위다. 공식 행정동/발달상권 경계를 가져온 것이 아니며 통계의 공간 집계 경계와 동일하다고 주장하지 않는다.

## 지도

Leaflet 1.9.4 + OSM 표준 배경지도. 화면에 필요한 타일만 요청하고 브라우저 캐시를 사용한다. 전체 지역 다운로드/오프라인 타일 저장은 구현하지 않는다. [OSM 타일 정책](https://operations.osmfoundation.org/policies/tiles/).

권역 색상은 현재 조건의 상대 순위, 숫자는 계산된 원점수다. 점수는 100점 만점이 아니다. 조건 미충족 권역도 회색 경계로 직접 탐색할 수 있다. 배경지도 실패 시 경계와 목록은 유지된다.
